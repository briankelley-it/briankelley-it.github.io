Thistledown Homes

A real estate website for a fictional home investment company. Visitors can browse homes for sale, filter listings, save favorites, find homes on an interactive map, and see past deals with calculated buyer savings.

I built it with Django models, views, and templates, plus an admin dashboard for managing listings and messages. A custom management command exports the pages to static HTML so this live demo runs on GitHub Pages.

Python · Django · JavaScript · MapLibre · SQLite
