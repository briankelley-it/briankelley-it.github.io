Web application

HouseLedger

A household finance app for tracking bills, recurring payments, budgets, properties, and receipts. Everyone in a household can see what’s due, record payments, and compare spending against monthly budgets.

Business rules live in a shared service layer used by the web pages, the REST API, and Celery background jobs. Payments run in database transactions with row locking, and every query is scoped to the user’s household.

  • Python
  • Django
  • DRF
  • PostgreSQL
  • Celery
  • Redis
  • HTMX
  • Tailwind CSS

Backend / REST API

LedgerAPI

An expense-tracking REST API with JWT authentication, spending categories, monthly budgets, and reports.

User-scoped queries keep accounts separate, decimal arithmetic protects monetary amounts, and SQL subqueries calculate budget totals. It ships with OpenAPI docs and tests with a 90% coverage minimum.

  • Django REST Framework
  • PostgreSQL
  • JWT
  • OpenAPI
